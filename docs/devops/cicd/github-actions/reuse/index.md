# Reutilización

Un reusable workflow comparte jobs completos; una composite action comparte steps; una custom action puede implementarse con JavaScript, Docker o composición. La [guía de reusable workflows y actions](reusable-workflows-and-actions.md) explica criterios de uso, mantenimiento y seguridad.
