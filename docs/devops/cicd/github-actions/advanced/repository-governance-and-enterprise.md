# Gobierno de repositorio y empresa

Branch protection, required checks, revisiones y CODEOWNERS establecen qué debe ocurrir antes de integrar un cambio. Los rulesets permiten expresar esos controles de manera gobernada.

En una organización madura, los equipos de plataforma pueden ofrecer reusable workflows centralizados; los equipos de producto los consumen y seguridad participa en estándares, permisos y excepciones. Esta separación reduce duplicación sin quitar responsabilidad a cada repositorio.

Consulta [workflows reutilizables](../reuse/reusable-workflows-and-actions.md) para definir contratos reutilizables.
