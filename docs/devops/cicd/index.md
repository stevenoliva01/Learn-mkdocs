# CI/CD

La integración continua (CI) valida cambios de forma frecuente; la entrega continua (CD) prepara o automatiza su promoción entre entornos. Este dominio comienza con [GitHub Actions](github-actions/index.md), la plataforma integrada de GitHub para definir esos flujos.
