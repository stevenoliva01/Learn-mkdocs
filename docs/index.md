# Learn

Base de conocimiento tecnica personal creada para organizar conocimiento durable y facilitar su consulta.

## Como esta organizada

- **Knowledge:** conceptos y explicaciones en su dominio canonico.
- **Cheatsheets:** referencias rapidas de comandos y consultas.
- **Runbooks:** procedimientos genericos, reutilizables, sanitizados y verificables.
- **Courses:** material pendiente de consolidar, sin copiar recursos de terceros.
- **Certifications:** planes y notas especificas de certificaciones.
- **Inbox:** contenido pendiente de clasificacion.

La navegacion se construye automaticamente a partir de la estructura de `docs/`.
